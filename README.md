## Интерфейс

**Рабочее пространство — центральный элемент ORION.** Мы уделяем внимание организации окон, доступу к инструментам и визуальной иерархии, чтобы сложные процессы оставались понятными.

> **Галерея интерфейса готовится.** Здесь будут опубликованы реальные, проверенные скриншоты приложения: обзор рабочего пространства, проекты и задачи, календарь, заметки и другие модули. Мы не используем концепт-арты вместо скриншотов работающего продукта.

## Принципы

**01 / Единый контекст.** Инструменты должны помогать друг другу, а не создавать новые информационные барьеры.

**02 / Модульность.** Рабочая среда развивается вместе с потребностями пользователя.

**03 / Управляемость.** Пользователь определяет структуру пространства и способ организации работы.

**04 / Практичность.** Интерфейс и функции оцениваются по тому, насколько они помогают завершать реальные задачи.

## Доступность

**KAIDEN ORION находится в активной разработке.** Основной фокус — настольное приложение для Windows.

На данный момент в этом репозитории **нет проверенного публичного установщика**. Когда будет готов выпуск для распространения, информация появится в разделе [Releases](../../releases).

> [!CAUTION]
> Не скачивайте сборки из неофициальных источников. Публикация ссылок на релизы будет сопровождаться отдельной проверкой установщика и материалов выпуска.
